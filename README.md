# Drizbøi Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript in a blue-and-silver cybersecurity aesthetic.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive layout, visual styling, and animations
- `script.js` — mobile navigation, back-to-top control, and current year
- `README.md` — setup and editing notes

## Run locally
Open `index.html` in a browser. No build tools or package installation are required. An internet connection is used only for the optional Google Fonts.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` with your real professional email.
2. Replace `YOUR_GITHUB_USERNAME` with your GitHub username.
3. Replace the LinkedIn placeholder with your actual profile, or remove that link if you do not use LinkedIn.
4. Add verified repository/demo URLs for `Frank’s Website` and `Drizboi_game`.
5. Add project screenshots, descriptions, and evidence of what you personally implemented.
6. Update skills and education details as they change. The cybersecurity lab project is clearly marked as planned, not completed.
7. Confirm whether you want to publish your full legal name or keep using the professional brand “Drizbøi”.

## Honest positioning
The portfolio describes the owner as a student and developing practitioner. It does not claim certifications, employment history, professional security engagements, or completed cybersecurity projects that have not been confirmed.
